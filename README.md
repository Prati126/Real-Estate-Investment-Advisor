# Real Estate Investment Advisor

A machine learning project for real estate investment analysis.

## Features
- Investment classification
- Five-year property value estimation
- Streamlit web interface
- MLflow experiment tracking

## Technologies
- Python, Pandas, Scikit-learn, Streamlit, MLflow

## Run Locally
Install dependencies using: pip install -r requirements.txt
Run the app using: streamlit run app.py

## Disclaimer
Future value assumes fixed 5% annual growth. It is not a guaranteed forecast.
Investment labels are heuristic and do not prove actual profitability.
